Machine Slices

One machine. One thousand windows.

A radial engine beats at the heart of the machine, 72 times a minute. Each beat sends a pulse of light down the vessels; where a pulse reaches a junction, the gear train there clicks forward. Every rhythm divides one minute, so the machine returns to the same moment every 60 seconds.
